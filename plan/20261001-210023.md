# 代码修改记录

- 完成时间：2026-10-01 21:00:23 Asia/Shanghai
- 修改目标：提供可直接体验的本地模拟微信登录。
- 影响范围：Python 认证后端、登录页面、本地配置。

## 修改摘要

启用本地开关后，点击微信登录并确认，即可用本地微信测试用户进入应用，复用现有会话及退出机制。

## 变更文件

- `backend/auth.py`：增加模拟模式识别及模拟登录接口，限制本机地址和来源，禁止生产环境使用。
- `src/components/LoginScreen.tsx`：识别模拟模式，显示确认提示并提交登录请求。
- `.env.example`：增加默认关闭的 `WECHAT_MOCK_LOGIN` 示例。
- `.env`：开启本地模拟登录。
- `backend/test_wechat_mock.py`：新增登录、会话、退出、账户复用和环境限制检查。
- `dist/`：重新构建前端产物。

## 行为与设计说明

模拟用户账号与真实微信账号独立；不请求微信服务。关闭开关后使用原有真实授权流程。此次模拟仅支持当前 Python 后端，旧版 Node 后端不提供模拟接口。

## 验证结果

- `python -m unittest backend.test_wechat_mock -v`：通过。
- `npm run lint`、`npm run build`：通过。
- 启动本地存储服务成功；在 `http://localhost:3004` 实测模拟模式、登录、会话、退出和首页均成功。
- 开发服务器曾因监听数据库锁文件出现 `EBUSY`；改用构建产物及无热重载的后端完成预览。未执行浏览器视觉检查。

## 后续事项

用户打开 `http://localhost:3004`，点击微信登录并确认即可体验。以后启动需先运行 `npm run storage:start`，再运行 `npm start`；端口以启动日志为准。开发服务器监听数据库目录的问题尚未修改。
