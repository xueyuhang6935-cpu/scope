## 行为与设计说明

- 源预览包含历史完成信息，仅数据管理员可读；调查员/审核人不直接访问，未来 Agent 仍须独立时点快照与字段掩码。
- 系统管理员不自动获得业务数据权或审核权；权限校验由后端执行。未来审批调用必须提供持久化的发起人，不能信任客户端自报。
- 同一进程以现有 SQLite 锁协调授权和数据读取，暂不支持多 worker；不新增框架和依赖。
- PostgreSQL 原供应链业务表已为空，没有执行数据库写入。LaDe 源库完整保留，摘要与迁移前相同。
- 备份位于 `data/backups/single-logistics-20261007-194707`；审核账号密码只在该忽略目录的凭据文件中。备份含账号秘密，不提交。多 SQLite 文件断电场景需整体恢复同一备份组。
- 旧前端源码仍可供复用，但正式应用只引用共享 CSS，不引入旧空间逻辑；旧核心保留不表示物流业务已建成。
