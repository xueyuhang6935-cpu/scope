# 可核验调查报告

新调查结果包含 `verified_report_v1`，网页、Markdown 和证据 ZIP 共用该结构。已完成历史任务按原结果重放；重新发起调查才生成新版报告。无需变更数据库表结构。

- 已确认事实：程序从当前任务的两期比较/分组证据生成，展示支付率、百分点差、分子分母、上海时区两期窗口、过滤、证据编号与行键。核验快照、范围、指标版本、证据哈希、日期、数值和单位。不可比数据不会产生事实。
- 描述性分析：只有完整分组、总量守恒且两期均可比时才发布分解；重新计算组内项和构成项，并验证二者之和等于总体变化。不同维度的分解不能相加，不证明因果。
- 待核实解释：使用已登记的候选解释模板，关联同范围已核验事实，列出替代解释、反证引用和缺失证据。替代解释由程序提供通用核实方向，不是额外观测结论；语义支持关系仍需人工核实。

模型可在 `finish_investigation.findings` 提交严格结构化事实引用，不能提交任意数值和因果文案。省略该字段时，由程序生成事实。错误报告只允许一次修正，整理阶段不再开放数据工具；修正仍受原模型、Token 和时间预算限制。连续失败返回 `report_validation_failed`，同时保留程序校验通过的事实。已有预算停止原因和待完成要求继续展示。

负例覆盖：正确数值配错误日期、渠道证据冒充设备证据、样例冒充全量、错误/超时冒充服务崩溃、外部任务引用、证据篡改、缺失分组和自由数值注入。报告不输出“下降集中于某组”一类未经全组对照验证的结论。

报告适用于动态异常调查；普通查询仍显示原有指标与图表。原始工具结果保留在证据附录，可供复核，但不作为根因断言。
