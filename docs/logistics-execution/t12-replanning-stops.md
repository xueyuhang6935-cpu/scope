# T12：重规划与停止规则

## 实际行为

T11的固定一次修订已替换为证据触发规则。程序只在保存观察出现有引用的`not_supported`/反证、实际工具`error/unavailable`、实际结果`truncated`或已授权人工约束版本变化时进入规划。普通missing文字、模型换说法和未知假设不会单独触发重规划。同一内容的触发去重；每次修订保存旧版、新版、步骤/假设差异、触发证据或约束ID、理由、时间与内容指纹。

计划校验沿用T10：不可删除或修改已执行步骤、伪造步骤状态、越权指定区域/时点、选择任意SQL。失败步骤导致依赖阻塞时停止，不能当作全部完成。报告必需工具失败转部分报告，不能无限重试或伪造模板。

## 预算服务与恢复

`backend/logistics_budget.py`统一读取、预留及记账。默认模型12次、工具16次、修订3次、已知Token24000、主动时间120秒。计数在操作前落盘，失败不返还；工具宿主入口统一计数，图、报告生成和HTTP直调不能绕过。各运行保存本地增量，读取汇总任务家族；家族限额取成员最小值，客户端不接受预算字段。

关联子运行继承父家族。同空间、同发起人、同业务快照指纹（含来源版本、范围、时点、口径和可见内容）的独立请求自动归入已有家族；换幂等键、问题、模式或重新创建同内容快照不能清零。不同发起人分别记账。关联另一已绑定家族的快照被拒绝，不隐式合并。幂等迁移回填历史链和指纹，并从已有调用审计补齐工具数量；旧记录中未保存的执行耗时无法精确复原，不虚构。

后台主动时间沿用租约增量，排队/等待不计时；宿主单独模型和工具调用时间另记，后台模型时间不重复相加。恢复、重启、关联重规划均读取同一累计值。到达调用/工具上限后不再发新调用；最后一次合法调用可交付并由程序收尾。Token和时间响应超额则阻止模型交付，程序从已有证据生成部分报告。供应商最终返回Token可能超过请求前剩余额度，实际用量如实累计，因此24000不是账单硬上限。

缺少Token回执标记`model_usage_unknown=true`并增加`unknown_usage_calls`。`model_tokens`只代表已知用量，不能解释为实际0；后续依靠调用数/时间上限继续限制。非法输出且用量未知不自动修复；网络失败仍终止且不自动重发。历史未知inflight节点继续转人工标记。

## 重复与无进展

调用签名包括快照指纹、工具名和规范化参数，省略默认参数与显式默认参数等价；同run重复步骤复用并校验保存证据，不再调用工具或模型观察。内容指纹去除run/证据/调用定位ID与排列差异，保留真实业务内容、状态、分页覆盖、指标和分母；读取同一保存证据不能制造新进展。

有效观察需引用本步骤实际证据或返回任务证据，工具为ok/empty，且内容此前未在家族有效观察中出现。连续两次无新有效观察停止，计数和指纹保存SQLite，换run或恢复不能清零。此规则是保守工程判断，不能证明自然语言结论正确；完整规划增量价值由T13验收。

## 人工约束入口

```http
POST /api/logistics/runs/{run_id}/constraints
Content-Type: application/json

{"instruction":"只做AOI风险比较，原因留人工核查"}
```

仅发起人、当前有调查范围权限、queued/running模型运行可写。说明1—1000字，版本与账号落盘；不能修改scope、预算、快照、工具白名单或执行权限。首工具执行前、工具之间及报告前检查变化，模型报告返回后亦检查版本。停止后返回409，不提供恢复能力；不是T16现场事实接口，也不把说明当作已证实事实。

## 停止及部分报告

停止原因枚举包括`model_call_limit/tool_call_limit/revision_limit/token_limit/active_time_limit/no_progress/blocked_dependencies/interrupted_operation/model_transport_failed/invalid_model_output/required_evidence_unavailable/evidence_limit`；撤权/取消继续使用既有运行错误与终态。

可交付的停止运行保存waiting状态、stop_reason、全部已落盘证据定位、未完成步骤和`source=program_stop_report`结构化partial报告。报告只引用已保存汇总数值、明确原因与未解项，使用T10校验，无新模型/工具调用。通过`GET /runs/{id}`及`GET /runs/{id}/investigation`读取，`/runs`显示停止原因、未完成项、家族累计用量和未知部分。T08模板另行保存；部分调查报告不冒充完整模板下载。

模型运行停止后不能再调用工具、模型或通过基础报告按钮发起新取数；证据仍可按当前权限读取。权限失效立即失败并阻止结果/证据/报告交付；取消结果同样不能迟到提交。人工恢复留T16—T18，多worker不支持。

## 验证

新增17项宿主T12测试与4项纯策略测试；使用真实LangGraph、SQLite、HTTP模拟模型和独立手算夹具，不读取正式源或调用真实供应商。覆盖四类触发、计划差异与指纹损坏、无证据不修订、首工具前约束变化、重复复用/两次空转、五项预算、未知回执、父子/换键/同内容新快照预算、旧审计回填、旧图缺字段恢复、飞行中时间耗尽、权限失效、必需证据失败和依赖阻塞。

沿用T11独立子进程磁盘恢复测试，增加家族修订/模型计数断言；取消、权限、未来不变性、报告、SSE与旧供应链核心全部回归。修改旧未来不变性测试复用同一未来输出，避免第三次无必要全工具查询触及新16次上限；保留未来内容相等和敏感字段断言。旧事件测试改为验证失败运行调用拒绝，再用可运行调查验证请求关联，未放宽保护。

结果汇总与源码/提示词指纹位于本地`test-results/logistics-t12/summary.json`；最终计数见[任务状态](task-status.md)。未运行真实模型、正式源模型联调、旧PostgreSQL场景、多worker或冻结评测。T13及G3未推进。已有后端需重启加载幂等迁移。
