# T05：未来不变性、权限与前端输入验收

工作台已接入真实时点快照和指标查询。选择参考时间、授权区域后创建快照，三指标卡片可在工作台内展开积压、逾期或临期任务，支持稳定分页及明确标注的当前页搜索。页面持续显示“历史回放／参考时间”、真实年份未知和样本覆盖限制；缺失指标显示不可计算及已知下界。

## 输入与权限边界

- `GET /api/logistics/snapshots/config` 只返回已保存批次、明确授权区域和参考时间元数据，使用既有业务读取权；没有业务权的系统管理员拒绝。不提供完整批次审计、源行或连接信息。
- 工作台默认参考时点 `2000-07-02 10:00:00`，优先区域 5，否则首个授权区域；也可显式选择全部授权区域。年份受页面约束及后端严格解析双重验证，非法日期不会被猜测或转换到真实年份。
- 修改时间/区域、重新加载范围时清空已展示结果；创建请求和任务查询在卸载时中止，过期异步响应不回填。权限轮询版本或账号变化重建工作台，清除旧指标和任务。权限查询失败时宿主不展示缓存业务页面。
- 浏览器只请求快照配置、创建、指标和掩码任务接口；调查员无需获得原始历史预览权。选择区域不等于授权，直接伪造 HTTP 请求仍由后端整体校验。
- 快照创建最多等待 120 秒；这仅是浏览器等待上限，不是 T06 持久化执行器。大范围创建与锁占用仍未容量压测。

## 未来不变性验收

`backend/test_logistics_g1.py` 使用隔离业务库、人工夹具副本和真实 HTTP 请求，改变合法 T 后完成时间/完成日期/GPS及派生标签，添加 T 后才接单任务。固定时刻的掩码行、汇总、任务前两页排序、AOI 分组和可见内容摘要均不变。规范化时只排除独立生成的快照 ID 和真实创建时间；没有去掉业务字段。可见内容不包含未来秘密标记，日志捕获同样无此标记。

GPS 组合门禁、原始缺失与未来采样输出一致、事件等于 T、T+H、近期左开端点、零时长、跨日和窗口未知由 T03/T04 测试共同覆盖。源版本变化可能改变溯源指纹，不能把溯源元数据变化当作业务结果变化。

目前没有物流模型工具、报告下载、证据导出或恢复入口，因此不伪造其端到端测试。此次检查受控 HTTP 业务 JSON 的完整响应和序列化内容，保证它们可作为后续模型/导出输入的安全基础；新增入口仍须在对应任务执行相同边界验证。

## 权限验收

除 T03/T04 现有测试外，专项将实际快照记录绑定到另一个工作空间，再直接请求掩码读取、汇总、任务和分组，四入口均拒绝。还覆盖区域缩权、混合授权区域、停用账号、删除账号、构建中撤权、已保存批次变化和伪造业务时点参数。删除账号后，即使宿主持有旧用户对象，也不能调用全量快照读取。

浏览器测试验证授权选项、参考年份输入、真实接口格式、不可计算与零值区分、卡片展开、翻页、修改输入清空旧结果、权限版本变化清空任务、无原始预览请求。现有权限故障、登录和导航回归继续保留。浏览器回归使用接口替身；真正权限和源数据边界由后端 HTTP 专项和真实源抽查验证，替身结果不冒充真实数据库浏览器联调。
