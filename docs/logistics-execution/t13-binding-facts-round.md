# T13 人员绑定、事实句与冻结对照

实施范围按用户确认方案：人员证据绑定和有限负荷补取、报告事实句生成、减少多余模型调用、冻结后完整稳定对照。未修改源任务、正式账号、模型型号、权限、家族预算、前端或T14。

## 实际行为

- 从同运行、同快照保存逾期证据确定重点人员。完整归属、过半或逾期降序越过并列边界才确定最高人员；并列人员分别检查负荷。
- 重点负荷步骤由证据绑定真实人员，轨迹保留原参数、实际参数和引用；显式指定其他人员的查询不静默替换。目标缺负荷时宿主有限补取，每个补取签名最多一次，失败不循环。权限、工具计数及家族预算使用原执行器。
- 指标句、负荷句、归属覆盖句和共同窗口句从绑定证据生成。窗口区分已观察子集与全部逾期，指标名称与分母不由模型自由改写。新报告事实绑定严格校验，旧保存报告仍可读取；模型原提议保留供审计。
- 模型报告接收已有证据的合法绑定选项，不接收独立评分答案。集中判断继续使用既有结构；原因标待核实推断，GPS缺失不能证明人员未到场。自然语言限制与其他说明仍非全面语义校验。
- 宿主补取无需模型观察；目标齐备直接收尾；支持目标修订无新待执行查询时转报告。实际请求记录预留、估算输入、输出上限、调用前已知用量和修复序号。
- 根据开发实测，报告单次输出上限由4000改2400，减少对观察的挤占；12次模型、16次工具、3次修订、24000 Token、120秒上限未改。估算仍非服务商计费保证。
