# 供应链工作空间：范围与公共布局

当前进度：工作台和风险列表已切换为 PostgreSQL 场景计算结果，支持自动扫描、事件合并及负责人管理；智能助手已接入缺料计算。以下页面骨架记录保留历史背景，最新范围与操作见 [缺料计算与自动风险监测](shortage-monitoring.md)。审批和执行仍为示例。

## 本次范围

依据 `汽车供应链Agent_前端设计说明书_V1.md` 的第 2、3、12、13 节完成公共布局和页面骨架。

- 保留登录选择、登录、注册、找回密码及账号设置，复用原有认证接口与 Cookie。
- 登录默认进入 `/workspace`。未登录打开详情会跳转登录，登录成功后恢复原详情和查询参数。
- 仅保留供应链业务入口。原订单分析页面、`/order-analysis` 路由和 `/api/analyst/*` 接口已移除。
- 账号设置在 `/account` 使用相同的侧栏、顶栏和配色，保留账号、安全、通知及微信绑定设置项，未接入的操作禁用。
- 工作台、智能助手、风险处置、审批中心、数据中心、运行记录和系统设置均有独立路由。
- 数据中心提供数据接入、数据目录、数据治理和数据预览；数据治理保留四个页签。
- 示例对象贯穿风险、审批、数据问题及运行详情。当前供应链页面不调用业务写接口，不表示业务服务已完成。

## 公共布局

- 桌面侧栏为 202 像素，顶栏为 69 像素，内容边距为 30 像素。窄屏使用可关闭的导航抽屉和表格内部横向滚动。
- 所有新版颜色集中在 `src/supply/supply.css` 的 `--sp-*` 变量；配色以说明书第 3.2 节为准。
- 主按钮使用浅紫背景和深灰文字；选中导航与链接使用深紫；业务状态独立使用绿、黄、红、蓝及文字、图标。
- `components.tsx` 提供按钮、状态标签、表格、页面标题、空态及保留工厂范围的链接。

## 路由与恢复

使用 `BrowserRouter` 和嵌套路由，详情链接可直接打开、刷新及分享。工厂范围保留在 `factory=all|A|B`；风险搜索、优先级、状态、排序、分页及详情页签保留在查询参数中。风险详情的 `from` 保留来源列表地址。滚动位置保存在按用户及地址区分的会话存储中。

供应链消息草稿按用户、工厂和会话或事件分开保存在会话存储中。存在未发送草稿时切换工厂需确认。当前没有已运行的供应链任务；未来接入任务后需补充后端运行状态检查。

未知对象及超出示例工厂范围的详情显示对象不可用；未知地址显示页面未找到。此范围筛选仅用于示例界面，真实数据授权仍必须由后端完成。

## 运行与验证

正常环境继续执行 `npm run dev`，前端默认 3003，代理默认 `http://localhost:3002`。后端使用其他端口时，在启动 Vite 前设置 `SCOPE_API_PROXY_TARGET`；例如本机现有后端为 `http://127.0.0.1:3004`。

```powershell
npm run lint
npm run build
npx playwright install chromium
npm run test:supply
```

浏览器测试使用独立模拟认证响应，不发送验证码、不创建真实审批、不调用模型。覆盖入口、详情直达、刷新、返回列表、工厂隔离、草稿、登录回跳及移动端溢出。截图保存在 `test-results`。

Vite 开发服务器和已有 FastAPI、Express 静态托管均支持回退到 `index.html`。部署到其他静态服务时，同样需将非文件、非 API 的页面请求回退到 `index.html`。

## 历史数据与代码清理

订单分析页面、旧侧栏、旧聊天、充值页面及订单分析后端桥接、路由、迁移和验证脚本已删除。应用启动只需认证 SQLite，不再初始化 PostgreSQL/S3，不再调用相邻订单分析项目。模型客户端依赖和 Python 分析存储依赖已移除。

现有账号库、历史订单分析数据、报告、数据库及 S3 文件均保留；相邻 `order-payment-analyst` 项目作为独立历史项目保留。`scripts/local-storage.mjs`、`scripts/backup-storage.mjs`、`scripts/restore-storage.mjs`、`scripts/verify-backup.mjs` 和 `server/object-storage.mjs` 仅用于手动维护历史存储，对应 `pg`、S3、`dotenv` 依赖继续保留。新应用不会自动启动这些存储服务，也不执行历史迁移。

## 后续边界

供应链助手、审批及执行服务尚未接入。文件导入、质量校验和单位换算治理现由 FastAPI + SQLite 提供真实数据流程，详见 [数据导入与治理说明](data-import-governance.md)。真实风险关闭和审批执行仍需后续业务服务。
